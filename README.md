# Sales-Data-Analyst-SQL-EDA-Project
Este proyecto analiza los datos de PedalProCyc, una empresa ficticia dedicada a la venta de bicicletas, ropa y accesorios de ciclismo a nivel internacional. El objetivo es identificar los productos con mejor desempeño, analizar la evolución de las ventas y comprender el comportamiento de los clientes para la optimización de la toma de decisiones.
